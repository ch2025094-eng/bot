服務條款

最後更新日期：2026 年 11 月 3 日

歡迎使用「𝖇𝖆𝖈𝖔𝖓 𝖙𝖎𝖈𝖐𝖊𝖙」（以下簡稱「本 Bot」）。當您邀請或使用本 Bot，即表示您已閱讀並同意本服務條款。如不同意，請停止使用本 Bot。

一、服務內容

本 Bot 提供 Discord 伺服器管理輔助功能，可能包含：

  • 票單建立、管理、關閉及對話紀錄匯出。
  • 新成員歡迎通知、考核通過公告及身分組發放。
  • 抽獎活動建立、倒數及得獎者抽選公告。
  • 票單分類、模板、權限及相關頻道設定。

實際功能依 Bot 版本及伺服器管理員設定為準。

二、使用規範

  • 不得利用本 Bot 從事違法、詐欺、騷擾或侵害他人權益的行為。
  • 不得干擾 Discord 平台、其他伺服器或使用者的正常使用。
  • 不得未經授權存取或散布他人的票單內容及個人資料。
  • 使用者應遵守 Discord《服務條款》及《社群準則》。

三、管理員權限與責任

伺服器管理員應妥善設定 Bot 的角色、頻道及權限，並確認 Bot 僅取得提供服務所需的權限。管理員亦應自行確認票單存取權限、紀錄保存及抽獎規則。

四、服務穩定性

服務可能因 Discord 平台異常、主機維護、網路問題、程式更新或其他不可預期因素而暫時中斷。我們不保證服務永不中斷、完全無錯誤或資料永久保存。

五、資料與隱私

資料處理方式詳見本頁「隱私權政策」。本 Bot 可能為提供功能而處理必要的 Discord 使用者、伺服器及訊息資料。

六、服務修改或終止

我們可能因維護、安全、功能調整或其他合理原因，修改、暫停或終止全部或部分功能；情況允許時將盡可能提前公告。

七、第三方服務

本 Bot 依賴 Discord 及可能使用的主機或其他第三方服務。第三方服務的可用性及資料處理方式，依其自身條款與政策為準。

八、條款修改

本條款可能不定期更新。更新後會修改本頁日期；您繼續使用本 Bot，即表示接受更新後的條款。

隱私權政策

最後更新日期：2026 年 11 月 3 日

本政策說明「𝖇𝖆𝖈𝖔𝖓 𝖙𝖎𝖈𝖐𝖊𝖙」（以下簡稱「本 Bot」）在提供 Discord 伺服器功能時，可能處理的資料類型及用途。

一、可能處理的資料

  • Discord 帳號資料：使用者 ID、使用者名稱、顯示名稱及頭像資訊。
  • 伺服器資料：伺服器 ID、頻道 ID、身分組 ID 及管理員設定。
  • 票單資料：票單類型、建立者、相關訊息、建立與關閉時間，以及匯出的 HTML Transcript。
  • 抽獎資料：活動設定、參加者識別資料、抽選結果及得獎者資訊。
  • 設定資料：票單模板、權限、頻道設定及維持功能所需的 JSON 設定。

本 Bot 不應要求使用者提供 Discord 密碼、驗證碼或帳號登入憑證。

二、資料使用目的

  • 建立、管理、關閉票單及匯出對話紀錄。
  • 發送歡迎通知、公告或執行管理員設定的身分組功能。
  • 執行抽獎、確認參加者及公告得獎結果。
  • 保存設定，讓 Bot 重啟後仍能維持必要功能。
  • 排除錯誤、維護服務安全及處理回報。

三、資料保存方式與期限

部分設定可能以 JSON 檔案保存於 Bot 使用的主機環境；票單 Transcript 可能依管理員設定匯出並保存於指定 Discord 頻道或其他位置。

保存期限取決於主機設定、備份方式及伺服器管理員操作。管理員應定期檢查備份與存取權限，並刪除不再需要的資料。

營運者請補充：主機資料保存地點、備份頻率、實際保存期限及資料刪除流程。

四、資料分享

本 Bot 不以販售使用者個人資料為目的。資料可能由具有相應權限的伺服器管理員、票單處理人員、提供託管服務的主機商，或依法有權要求資料的機關接觸。

請勿在票單或公開頻道中傳送不必要的敏感個人資料。

五、資料安全

我們會採取合理措施降低未經授權存取、遺失或不當使用資料的風險，但網路傳輸及電子儲存無法保證絕對安全。請勿透過本 Bot 傳送密碼、金融帳戶資料或其他高度敏感資訊。

六、資料查詢與刪除

如需查詢或要求刪除相關票單或其他資料，請聯絡該 Discord 伺服器管理員，或透過下方聯絡方式提出。基於安全、爭議處理或法律要求，部分資料可能需要在合理期間內保留。

七、未成年人

本 Bot 依附於 Discord 平台運作。使用者應符合 Discord 對其所在地區及年齡所訂的使用資格與規範。如監護人認為有不適當的個人資料處理情形，請透過下方方式聯絡。

八、第三方服務

本 Bot 可能透過 Discord API 及託管平台提供服務。第三方如何處理資料，依其自身隱私權政策為準。

九、政策更新

本政策可能因功能、法規或資料處理方式變更而更新；更新後會修改本頁日期。
